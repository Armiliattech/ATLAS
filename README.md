# ATLAS

ATLAS é um assistente pessoal de inteligência artificial baseado no Hermes Agent.

O projeto busca integrar IA, automação do Windows, memória, voz, wake word e ferramentas em um assistente pessoal inspirado em sistemas como J.A.R.V.I.S. O intuito é automatizar as tarefas do computador a ponto de apenas dizer os comandos com a própria voz, enquanto o sistema entrega o resultado à maneira pedida. Deverá ser capaz de manipular arquivos, fazer resumos, gerar imagens, organizar a agenda pessoal do usuário e ser um assistente de ensino, cumprindo todos essas competências com êxito.

## Status

Até então possuí o Hermes Agent com o ChatGPT integrado, na qual responde as perguntas corretamente em PT-BR no terminal e é capaz de realizar tarefas simples. Para as mais complexas, é necessário conceder permissão pelo terminal até então, haja vista que a intenção inicial é permitir automatizar tarefas mais elaboradas sem dificuldades.
